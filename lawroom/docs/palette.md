# Lawroom renk paleti

Kiremit / terracotta yönü; Dietroom yalnız yerleşim ve akış referansıdır.

| Kullanım | Renk |
|---|---|
| Ana vurgu ve düğmeler | #A34F36 |
| Koyu vurgu / hover | #813C28 |
| Sıcak krem zemin | #FAF6F1 |
| Yumuşak kil yüzey | #EFDFD1 |
| Gezinme zemini | #F1E6DC |
| Ana metin | #3F302A |
| İkincil metin | #766359 |
| Kenarlık | #E6D8CD |

Takvim türleri renk yanında ad/rozet taşır: duruşma mürdüm, görüşme gri-mavi, dosya takibi amber. Kaynak .pen dosyası ve tasarım üretim betikleri de aynı sıcak palete güncellendi.
